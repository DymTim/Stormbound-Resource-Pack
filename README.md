# 🐈 Stormbound Resource Pack

The official resource pack for the **Stormbound Minecraft Network**.

This pack contains custom assets used across Stormbound servers, including graphical rank tags, custom font glyphs, icons, and other network resources.

## ✨ Features

- Custom pixel-art rank tags
- Player and staff rank glyphs
- Stormbound network branding
- Custom Minecraft font assets
- Designed for Minecraft 1.21.1

## 📦 Installation

The resource pack is automatically downloaded when connecting to the Stormbound network.

Manual installation is not required.

## 🎨 Rank Tags

Custom tags are included for:

**Player & Supporter**
- Apprentice

- Technician

**Staff**
- Helper
